## Method

- Per-module time is `lake env lean <M>.lean` with every import already built (step 2), so it is the module's own elaboration and kernel check, not its dependencies. The full build is the parallel cold build of all entry modules (the core libraries and the shared packages are prebuilt).
- Every per-module time includes loading the imported `.olean` files (a few seconds; the floor row above), so small modules are dominated by it.
- A FAILED module (the entry is still changing) is timed up to its error; modules that import it were checked against the previous build products of step 2 only if those exist.
- Peak RSS is `/usr/bin/time -v`'s maximum resident set size (the largest single process).
- Copied lines: whole files whose header says "Provenance: copied from leanerVM" (modified copies) or from the S2a baseline entry, and `section Copied*` blocks; counted with `loc.py`'s code-line rule. Everything else is written for this entry.
